RallyFlow Privacy Policy

Effective 2026 · applies to RallyFlow 1.0 and later

Short version: RallyFlow stores all data locally on your device. It makes no network requests. There is no analytics or telemetry. Backups and exports are files you control.

What RallyFlow stores

When you run open play, RallyFlow saves what you enter — session names, player names and nicknames, check-ins, court assignments, scores, game history, awards and your appearance settings — in a single database file on the computer where the app is installed:

  • macOS: ~/Library/Application Support/pickleball-open-play
  • Windows: %APPDATA%\pickleball-open-play

Automatic safety backups are kept in the auto-backups folder next to it.

What RallyFlow sends

Nothing. RallyFlow makes no network requests of any kind:

  • no accounts, sign-in or cloud sync;
  • no analytics, telemetry, crash reporting or usage tracking;
  • no advertising or third-party SDKs;
  • no automatic updates or "phone home" checks.

The app blocks every non-local request inside its windows, and it works the same with Wi-Fi switched off.

Backups and exports

When you choose Create backup, Export (CSV or Excel), Save as image or Save certificates, RallyFlow writes a file to the place you pick. Those files are yours: we never see them. Treat them like any other file containing people's names, and share them only with people who should have them.

Players' information

The organizer decides what to record. We recommend using first names or nicknames and telling players that results may be shown on the big screen and in exported reports. To remove a person's data, delete the sessions they played in, or remove the app's data folder entirely.

Children

RallyFlow is a tool for organizers and is not directed at children. It collects nothing from anyone, because it collects nothing at all.

This website

The RallyFlow website is a static page with no cookies, no analytics and no third-party scripts or fonts. If it is hosted on GitHub Pages, GitHub may keep standard server logs under its own privacy policy. Downloads are served by GitHub Releases.

Changes

If this policy ever changes, the new version will ship with the app and on the website, with a new effective date.

Contact

Questions about privacy: contact the RallyFlow owner through the channel where you obtained the app (for example the GitHub repository's Issues page).
